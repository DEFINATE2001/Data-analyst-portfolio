DEFINATE MUDARIKWA — DATA ANALYST PORTFOLIO

No installation or build is required.

FILES
index.html: page content, education, experience and contact links
style.css: appearance and mobile layout
projects.js: project titles, descriptions, tools and optional project links
app.js: renders project cards

GITHUB PAGES DEPLOYMENT
1. Extract this ZIP.
2. Create or open a public repository named DEFINATE2001.github.io.
   This name gives you the user site at https://definate2001.github.io.
   A repository with another name uses an extra path in its URL.
3. Upload the extracted files directly to the repository root. Do not upload
   the ZIP itself or put index.html inside a folder.
4. Commit the files to main.
5. Open Settings > Pages. Under Build and deployment, choose Deploy from
   a branch, select main and /(root), then Save.
6. Open the published URL shown by GitHub once deployment finishes.


UPDATING PROJECTS
Edit projects.js. Copy an existing object to add a project. Change link:null
 to link:'https://your-real-project-url' to show a View project link.
Use real outcomes and published dashboard images when available.

LINKEDIN AND PHONE
In index.html, find the contact section. Add links using your actual details:
